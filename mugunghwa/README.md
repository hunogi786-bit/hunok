# 무궁화 꽃이 피었습니다

노트북·태블릿 카메라가 술래가 되는 몸놀이 게임입니다.
술래가 "무궁화 꽃이 피었습니다~"를 부르는 동안 제자리에서 달리고 팔을 흔들면 내 캐릭터가 앞으로 가요.
**"얼음!"** 하고 술래가 돌아봤을 때 움직이면 걸려서 뒤로 가요. 먼저 꽃까지 도착하면 이겨요.

## 여는 방법
- 인터넷 주소: `https://hunogi786-bit.github.io/hunok/mugunghwa/` (GitHub Pages가 켜져 있을 때)
- 카메라 권한을 물어보면 **허용**을 누르세요.
- `index.html` 파일을 더블클릭해서 열면 동작하지 않아요. 브라우저 보안 때문에 인터넷 주소(https)로 열어야 카메라와 설치 기능이 돼요.

## 홈 화면에 설치하기
- **크롬·엣지(노트북, 안드로이드 태블릿):** 처음 화면의 **홈 화면에 설치** 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘을 누르세요.
- **아이패드·아이폰(사파리):** **공유** 버튼 → **홈 화면에 추가**를 누르세요.
- 한 번 설치하고 열어 두면 몸 인식 파일까지 기기에 저장돼서, 그다음부터는 인터넷이 없어도 할 수 있어요.

## 설정
| 설정 | 선택 |
|---|---|
| 몇 명이 할까요? | 혼자 / 둘이서 (화면 가운데 선을 기준으로 왼쪽 1P, 오른쪽 2P) |
| 술래 눈치 | 너그러움 / 보통 / 매의 눈 |
| 술래 목소리 | 켜기 / 끄기 (끄면 글자와 효과음으로만 알려 줘요) |

### 술래 눈치 3단계
| 단계 | 돌아본 뒤 봐주는 시간 | 걸리는 움직임 | 걸리면 뒤로 |
|---|---|---|---|
| 너그러움 | 1초 | 크게 움직일 때만 | 12걸음 |
| 보통 | 0.75초 | 보통으로 움직일 때 | 18걸음 |
| 매의 눈 | 0.55초 | 조금만 움직여도 | 24걸음 |

도착까지는 100걸음이에요. 노래 길이는 매번 달라서(빠르게·보통·느리게) 눈치껏 멈춰야 해요.

## 수업할 때 팁
- 카메라에서 2~3m 떨어져 머리부터 발까지 보이게 서요. 바닥에 테이프로 자리를 표시하면 좋아요.
- 둘이서 할 때는 각자 자기 쪽 화면에만 있어야 해요. 가운데 선을 넘으면 상대편으로 인식될 수 있어요.
- 화면 아래 **움직임 막대**를 보면 내가 얼마나 움직이는지 보여요. 얼음일 때 막대가 검은 선을 넘으면 걸려요.
- 창문을 등지고 서면(역광) 인식이 잘 안 돼요.
- 카메라가 없을 때는 키보드 `A`(1P)·`L`(2P)를 누르고 있거나, 화면 왼쪽·오른쪽을 누르고 있으면 움직여요.
- 단축키: `Enter` 시작 · `Space` 일시정지 · `F` 전체화면

## 개인정보
- 몸 인식은 기기 안에서만 해요. 카메라 영상은 화면에 보여 주기만 하고, 저장하거나 어디에도 보내지 않아요.
- 앱은 자기 폴더의 파일만 쓰고, 다른 사이트에 접속하지 않도록 브라우저 보안 규칙(CSP)으로 막아 두었어요.
- 몸 인식에는 Google MediaPipe Pose Landmarker를 사용하며, 필요한 파일을 `vendor/mediapipe/`에 함께 넣어 두었어요 (Apache License 2.0).

## 숫자 조정 (개발용)
놀이 규칙 숫자는 `app.js` 위쪽에 모여 있어요.
- `MOVE_GAIN`: 크면 더 빨리 도착해요 (지금 9).
- `LEVELS`: 단계별 멈춤 기준(`threshold`), 봐주는 시간(`grace`), 걸리기까지 계속 움직여야 하는 시간(`sustain`), 뒤로 가는 거리(`back`).
- 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려야 설치된 앱도 새 버전으로 바뀌어요.
